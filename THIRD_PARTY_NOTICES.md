# Third-party theme notices

Teak includes color palettes derived from the following permissively licensed
open-source editor themes. The palette values are used as data; Teak does not
bundle their editor extensions.

- GitHub Dark and GitHub Light: [github-vscode-theme](https://github.com/primer/github-vscode-theme), MIT License.
- Tokyo Night: [tokyo-night-vscode-theme](https://github.com/tokyo-night/tokyo-night-vscode-theme/blob/master/LICENSE.txt), MIT License.
- Ayu Mirage: [vscode-ayu](https://github.com/ayu-theme/vscode-ayu), MIT License.
- Solarized Dark and Solarized Light: [solarized](https://github.com/altercation/solarized), MIT License.
- Catppuccin Mocha and Catppuccin Latte: [catppuccin](https://github.com/catppuccin/catppuccin), MIT License.
- Gruvbox Dark: [gruvbox](https://github.com/morhetz/gruvbox), MIT/X11
  License.
- Monokai: the built-in [Code OSS Monokai theme](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/monokai-color-theme.json),
  under the VS Code repository's MIT License. This is not Monokai Pro.
- Night Owl:
  [night-owl-vscode-theme](https://github.com/sdras/night-owl-vscode-theme),
  MIT License.
- Material Palenight:
  [vscode-palenight-theme](https://github.com/whizkydee/vscode-palenight-theme),
  MIT License. This open Material-inspired palette is distinct from commercial
  Material Theme products.

The existing Dracula, Nord, and One Dark palettes retain their respective
project attributions and are listed here for completeness:

- Dracula: [dracula-theme](https://github.com/dracula/dracula-theme), MIT License.
- Nord: [nord](https://github.com/arcticicestudio/nord), MIT License.
- One Dark: [one-dark](https://github.com/atom/one-dark-syntax), MIT License.
